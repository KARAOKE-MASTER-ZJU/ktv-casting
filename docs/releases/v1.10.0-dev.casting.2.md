# v1.10.0-dev.casting.2

修复媒体代理后续分段请求失败，提升 DLNA 投屏兼容性。

- 统一 DASH 索引和媒体缓存请求的客户端标识；Bilibili 请求保持原样。
- 上游 HTTP 错误显示真实状态码和请求范围，不打印包含签名的 URL。
- 无新增依赖，不使用外部解析器、运行时或 token 服务。
- 保留现有纯 Rust DASH 混流和本地代理实现。

本机对公开测试媒体验证 720P 和 1080P，均生成 H.264 + AAC、241.301 秒的 MP4，HEAD 及首/中/尾三个 64 KiB Range 全部通过。默认库测试通过；网络测试需显式运行：

```sh
cargo test --locked --lib
```

网络代理验证不代替 Android 真机与电视解码验证，本版保持预发布。

App 使用配套预发布版本及 Rust 依赖；二进制构建覆盖 Android 四 ABI 和桌面平台。
