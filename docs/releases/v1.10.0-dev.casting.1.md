# v1.10.0-dev.casting.1 整合说明

合并版 Rust 引擎预发布：

- 保留 KARAOKE 上游自动切歌修复、旧进度隔离、心跳补漏与重新投屏 JNI 接口。
- 整合曲目级缓存、可定位 MP4、并行 Range 读取与定位预取。
- 优化媒体请求兼容性，并复用现有本地代理和 DASH 混流能力。
- 重新投屏等待窗口适配双轨冷启动，补充异常 MP4 元数据检查。
- Android 四 ABI 使用 NDK 生成 QuickJS 绑定，保留最新 App 所需 JNI 接口。

## 产物

- Android：arm64-v8a、armeabi-v7a、x86_64、x86。
- CLI：Linux x86_64 musl、Windows x86_64、macOS aarch64。
- SHA256SUMS：校验所有七个二进制文件。

## 验证与边界

本地 Rust 测试通过，网络测试默认忽略。媒体服务的 HEAD 与首/中/尾 Range GET 验证通过；Bilibili 匿名 1080P DASH 获取通过。

尚未完成 Android 真机和电视解码回归，所以维持预发布。

App 应从 KARAOKE 最新主线接入，并使用对应的 Rust 预发布库。Rust PR #6 保留了两条开发线的作者与提交历史。
